# MAR3023 · Exam 1 Trainer

An unofficial, student-made study web app for **Principles of Marketing (MAR3023)**, Exam 1.
Covers chapters **1, 3, 4, 5, 6, 8, 9** with lessons ranked by what's actually tested,
flashcards, a high-yield "weird facts" deck, a big bank of real practice-exam questions,
infinite computational drills, a question-pattern trainer, and a timed mock exam.

## 🔑 Passcode
The site is protected by a simple class passcode. To change it, edit the line near the
bottom of `index.html`:

```js
var PASSCODE = "MAR3023";
```

> Heads-up: this is a *deterrent*, not real security. A static site can't truly hide its
> files — it just keeps the app away from casual visitors and search engines. Don't post
> anything you wouldn't want a classmate to eventually find.

## ▶️ Run it
- **Online:** open the GitHub Pages link (Settings → Pages).
- **Locally:** just open `index.html` in any browser — no install, works offline.

## 🧰 Features
- **Learn** — each chapter ranked High/Med/Low by test frequency; every concept paired with a real past-exam question.
- **Facts** — the specific stats & lecture examples that show up as "gotcha" questions.
- **Cards** — spaced-repetition flashcards.
- **Quiz** — 228 questions: timed mock exam, pattern trainer, the real practice exam, lecture-only, and per-chapter sets. Every question has an explanation and a ⚑ flag button.
- **Drills** — randomized Market Share, Multi-Attribute Model, NPS, TLC/Value Analysis, Vendor Analysis, Indexing, and Benefit Segmentation problems with step-by-step solutions.
- **Cram** — one-screen rapid review: formulas, mnemonics, and the highest-yield hit list.
